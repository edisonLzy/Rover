# Rover 发布短片分镜

| 时间     | 画面                                         | 屏幕文案                         |
| -------- | -------------------------------------------- | -------------------------------- |
| 0–4.5s   | 散落的 Agent 会话、终端和状态卡片汇聚成问题  | Agent 越多，进展越难一眼看清。   |
| 4.5–8s   | 品牌图标从像素光点中亮相                     | 认识 Rover / 你的桌面 Agent 搭档 |
| 8–13s    | 一条自然语言目标流向 Code Agent，并形成 Task | 说出目标。下一步，自有人接手。   |
| 13–18s   | 任务卡片从分散排列到整齐可读，状态持续变化   | 每个任务，都看得见。             |
| 18–22.5s | 需确认提醒与原会话入口被点亮                 | 需要你时，及时出现。             |
| 22.5–27s | 图标、品牌字标和最终宣言定格                 | 专注创造。其余交给 Rover。       |

声音：原创合成器音轨，开头克制，中段按功能节奏增强，片尾以品牌音型收束。无旁白，适合静音自动播放；主要叙事都由画面文字承担。
