# Rover 产品交互原型

打开 [index.html](./index.html) 即可体验，无需构建。此原型与[Rover 产品能力边界与核心交互](../architecture/Rover%20产品能力边界与核心交互.md)对应，使用固定的 1920 × 1080 桌面画布；顶部可切换整屏比例或放大 Rover。拖动宠物可以改变位置，位置保存在当前浏览器。

## 建议评审路径

1. 输入「帮我设置一个定时任务」，查看 Rover 自动匹配的 `scheduled-task`；再输入「`/scheduled-task` 每天 09:30 检查支付链路告警」，查看显式 Skill 引用。
2. 新 Task 卡片显示任务描述和纯文本执行摘要，动态边框提示仍在处理。点击卡片进入不含对话内容的会话跳转占位；用**模拟进度更新**查看卡片摘要如何跟随 Agent 状态变化。
3. 在跳转占位中选择**模拟 Agent 请求用户**，卡片会出现**去确认**。再次进入占位并选择**模拟在 Agent 中完成确认**，观察纯文本摘要更新。
4. 选择**模拟 Agent 完成**，卡片切换为稳定边框，显示 Markdown 完成摘要和**查看会话**；再查看定时计划和「经验与草稿」中的 Skill 草稿。
5. 选择**QA 发布确认**，确认按钮仍在处理中卡片内；输入「我想调研 XX 问题，请使用 `@Claude Code` 完成相关调研」可验证直接派发与摘要展示。

顶部场景菜单还提供故障排查、失败后续办、通知收件箱、Skill 目录和语音输入示意。任务列表不放状态分组 label，以卡片动态边框区分处理中的任务；失败与取消也用完成态卡片呈现，但摘要明确写明结果。输入框使用简化规则模拟 Rover 的轻量意图识别；它不代表最终实现方式。Rover 不设补充任务输入框，后续交互进入对应 Agent Session。

原型中的会话跳转、定时触发、Skill 目录、任务状态与保存操作均为浏览器内演示数据。跳转页不展示 Agent 会话内容。原型不会启动 Claude Code/Codex、创建真实定时任务、安装 Skill 或写入外部服务。除宠物位置外，刷新页面会恢复初始演示状态。
