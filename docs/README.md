# Rover 桌面宠物 Agent 原型

打开 [index.html](./index.html) 即可体验。原型画布固定为 **1920 × 1080 像素**，模拟 Mac 桌面、开发窗口和 Dock。Rover 默认以小悬浮件待命，位于桌面右下方；点击宠物展开输入条和任务卡片，按住宠物拖动可把它放到桌面其他位置。

顶部“整屏比例”显示 Rover 在完整桌面上的真实占比；“放大 Rover”以 100% 像素查看并操作局部区域。待命控件约 201 × 173 像素，展开任务约 420 × 370 像素，会话对照仅在主动打开时扩展到约 600 像素宽。右上角“体验场景”用于跳转设计状态，不属于日常产品界面。

拖动在两种预览比例下都可用。宠物接近桌面边缘时，展开内容会在画布内调整位置；靠近底部时可显示在宠物上方。宠物位置保存在当前浏览器，刷新后仍会保留；顶部“重置位置”可恢复默认停靠点。

## 主要交互

- **主动输入**：输入 `@Codex`、`@Claude Code`、`@OpenCode` 派发任务；也可从悬浮态选择语音入口，模拟转写后检查文本再提交。
- **被动告警**：监控命中规则时自动创建 `INC-482` 并启动只读排查；桌面宠物角标与通知卡片只负责提醒和跳转。
- **多任务**：每张卡片代表一个 Task，点击查看执行链、状态和补充指令。关闭界面不改变任务状态。
- **审批**：卡片说明请求方、命令、影响和理由。等待决策时只暂停当前 Run。
- **资源与调度**：可查看 QA 部署锁造成的排队、定时任务触发，以及失败后的重试和切换执行器。
- **经验**：历史处理记录作为可审阅的线索附加到任务。

## Rover 与 Coding Agent 的会话对照

在首页点击“线上结算页白屏”→“会话对照”。六个步骤分别展示：启动 Claude Code、请求生产日志、给同一会话补充指令、根据分析结果派发 Codex、审批推送、结果回写。左侧是 Rover 记录的 Task / Run / Event，右侧是**模拟的本地终端实例**，展示工作目录、命令、PID、Session ID 和输出。其他 Coding Agent 任务也可打开对应的终端实例示意。

终端命令与事件只用于产品原型，不会真的启动 Claude Code、Codex 或 Skill。Claude Code 的 `-p`、`--output-format stream-json` 与 `--resume` 形式参考[官方程序化运行文档](https://code.claude.com/docs/en/headless)；Codex 的 `codex exec --json` 形式参考[OpenAI 官方说明](https://developers.openai.com/zh-Hans/docs/enterprise/access-tokens)。终端中的 PID、ID、输出内容都是演示数据。

页面无需构建步骤。除宠物位置外，其余演示状态只在当前浏览器页面内存中保存，刷新后恢复初始场景。
